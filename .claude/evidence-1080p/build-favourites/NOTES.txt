THE FIVE ASKED FOR

   comment labels also lose ';' (-> space) and '"' (-> '). Tested against a
   transcription of ioq3 1.36 Cbuf_Execute (code/qcommon/cmd.c): every command
   the engine would run out of our block is one seta/set line, for hostnames
   carrying ';', '"', CR, LF, NUL, DEL. same_favourites() refuses to call a file
   "unchanged" when an existing favourite line has an unsafe comment, so an old
   dirty block is rewritten.
2. Team Arena: TITLES["missionpack"] (engine q3cache, accepts {missionpack},
   strict_accepts - internet rows must be gamename missionpack too), derived from
   every `ioquake3` row whose dir has a missionpack\ subfolder. sync.push_servercache:
   REGREAD HKCU Shell Folders\AppData -> <AppData>\Quake3\servercache.dat; never
   creates a folder; BUSY while ANY Q3 client runs (quake3.exe, ioquake3*.exe) and
   PROCLIST re-checked right before UPLOAD; reads back and compares; FAILED on any
   mismatch; a file that is not the 1.36 layout is refused.
   Layout proven two ways (servercache-layout-verification.txt): ioq3 source at
   06954842 (the 1.36 release point, box says "ioq3 1.36 ... Apr 12 2009") and the
   staged ioquake3.x86.exe (md5 12f99bc0f9ba416ee477a4f13de8feaa) disassembled:
   cmp size,0xa9200; reads 0xa4000 + 0x5200; CL_SetServerInfo offsets; NA_IP == 4;
   NET_CompareAdr compares type + 4 ip bytes + port only.
   Ownership: our records carry b"retro-fleet-fav\0" in netadr_t.ip6 (never read for
   NA_IP; LAN_AddServer leaves stack garbage there itself; copied verbatim on save).
   Only marked entries are ever removed; numglobal + 4096 global records + the
   player's favourites are carried byte for byte.
3. BUSY per FILE: sync.plan_targets() groups titles by target path (case-insensitive);
   a file is BUSY if the exe of ANY title that reads it is running; one result line

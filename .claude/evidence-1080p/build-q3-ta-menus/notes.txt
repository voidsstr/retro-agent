Design decisions (details are in the apply.py docstring):
- The Video Mode lists gain "Native" -1 as their FIRST entry.
- Three decoration text items show r_customwidth, the separator ("*" in the
  main menu, "x" in game) and r_customheight. They are gated by cvarTest r_mode
  showCvar { "-1" ; "-1.000000" }.
  - Item_Text_Paint paints a cvar-only item's value, but Item_SetTextExtents
    aligns by textWidth(item->text), which is 0 when text is NULL. Such an item
    is therefore always left-anchored, so the x positions are pinned.
  - An EDITFIELD without text would paint the value twice.
  - botlib concatenates adjacent strings, so the ';' in the gate list is required.
  - The UI writes r_mode with force (not latched) as "%i", so the gate follows
    a click at once (.240 54-B-condump-rmode.txt: r_mode "1" after one click).
- The Quality (ui_glCustom) itemDef is removed from both files.
- Layout was checked against the glyph advances in pak0's fontImage_12/16.dat.
  Worst case: a 3 px gap for a 2560 width. Tallest height ends at x 254 in game,
  against the frame at 261.
- The validator (a botlib+ui_shared mimic) parses all 53 stock TA menus with no
  errors. Top-level brace imbalance is compared relative to the original,
  because 21 stock files are unbalanced at the top level, which the game ignores.

# N5R5L9 — 192.168.1.243 (Compaq Deskpro 2000)

The fleet's oldest machine and its **only genuine Pentium 1 / Windows 98** box —
a 1997 Compaq Deskpro 2000 business desktop. Agent v1.16.0 on port 9898.
Read via `SYSINFO`/`VIDEODIAG`/`AUDIOINFO` and the custom
[`agent/tools/hwscan.c`](../../agent/tools/hwscan.c) (CPUID + full PCI + chipset).

## Hardware

| Field | Value |
|---|---|
| **CPU** | Intel **Pentium (P54C)** — GenuineIntel, family **5** / model 2 / stepping 12 (CPUID `0x052C`). Single core, ~100–166 MHz class. |
| **CPU features** | FPU, TSC, MSR, CX8. **NO CMOV, NO MMX, NO SSE** (all family-6+). |
| **Chipset** | **Intel 430HX "Triton II"** north bridge (82439HX, PCI `8086:1250`) + **PIIX3** south bridge (82371SB, `8086:7000` ISA bridge / `8086:7010` Bus-Master IDE). |
| **RAM** | **31 MB** (≈32 MB, 1 MB reserved). All SIMM slots currently populated. |
| **Video** | **Cirrus Logic GD5436 PCI** (`1013:00AC`), 2D-only SVGA, running 640×480 × 8-bit. DirectX 6.1. **No 3D.** |
| **Audio** | **Creative Sound Blaster 16 Plug-and-Play** (ISA, `sb16.vxd`) at I/O **220h**, 16-bit stereo + Gameport joystick. |
| **Storage** | C: ~1.2 GB IDE HDD (~1 GB free); A: 3.5" floppy; D: CD-ROM. No S.M.A.R.T. |
| **OS / BIOS** | Windows 98 **SE** (4.10.2222); system BIOS dated **1997-04-25**. |

## ⭐ Recommended upgrade: RAM (highest-impact, do this first)

**31 MB is the machine's single biggest limitation** — Windows 98 SE barely
fits, so it swaps constantly and is glacial (agent auth handshakes take
40–150 s). The chipset makes the fix clear-cut:

- It's an **Intel 430HX**, the *business* Triton chipset, which **caches the
  full installed RAM** (up to 512 MB) — unlike the consumer 430FX/VX/TX, where
  only the first 64 MB is cacheable. **So more than 64 MB IS worthwhile here and
  stays fully fast.**
- **All SIMM slots are already full** (≈32 MB = 4 × 8 MB), so upgrading means
  **replacing** the sticks, not adding.
- **Buy: 72-pin EDO DRAM SIMMs, 60 ns, 5 V, in matched pairs.**
  - **Ideal: 4 × 32 MB = 128 MB** (the 430HX caches all of it; 32 MB is the
    per-SIMM max these boards reliably take — 64 MB SIMMs are usually not
    recognized).
  - **Cheaper solid option: 4 × 16 MB = 64 MB.**
- **Parity gotcha:** the 430HX supports parity/ECC and Compaq business boxes
  often expect it. Check the installed SIMMs — **×36 organization (extra chip,
  ~9/12 chips per side) = parity; ×32 (8 chips) = non-parity** — and match it,
  or you may get a POST error / wrong memory count.

Going 32 → 64/128 MB turns this from a swap-bound crawl into a genuinely usable
Windows 98 machine. No software change can substitute for it.

## Software / driver notes

- **Sound (Windows 98):** the SB16 already works with the in-box Microsoft
  `sb16.vxd` driver — no action needed for Windows audio.
- **Sound (DOS / MS-DOS mode):** DOS games find the card via the
  `BLASTER` environment variable (set in `AUTOEXEC.BAT`, e.g.
  `SET BLASTER=A220 I5 D1 H5 P330 T6`). Because it's a **PnP** SB16, pure-DOS
  use also wants Creative's `CTCM` config utility to activate the card; the DOS
  driver package is on the share at
  `Drivers\Creative\DOS\Sound Blaster DOS\` (AWE64 set — SB16-superset, includes
  CTCM). Win98's "Restart in MS-DOS mode" generally carries the Windows PnP
  config, so BLASTER alone covers most games.
- **DOS games:** the classic shareware set (Doom, Wolf3D, Duke Nukem 1/2,
  Commander Keen 1/4/Dreams, Heretic, Hexen, ROTT, Jazz Jackrabbit, Tyrian,
  Raptor, Epic Pinball, OMF 2097, Wacky Wheels, Hocus Pocus, Blake Stone,
  Shadow Warrior — ~58 MB) **plus Duke Nukem 3D registered v1.5 (all 3
  episodes)** staged under **`C:\games\`** (one short 8.3 folder each, e.g.
  `C:\games\DOOM`, `C:\games\DUKE3D`). Most shareware zips are id/Apogee
  *installers* (run `INSTALL` once at the box). This box runs any DOS game
  well; the only caveat is *too-fast* timing on pre-1993 titles.
- **Run DOS games in MS-DOS mode, not a Windows DOS box** — with only 31 MB,
  Windows itself consumes most of RAM; "Restart in MS-DOS mode" frees all of it
  (which Duke3D etc. need) and is faster. `CACHE.COM` (see below) is on the DOS
  PATH for the too-fast early-'90s titles; leave cache ON for anything 1994+.
- **`CACHE.COM`** (built from `agent/tools/`, staged at `C:\WINDOWS\COMMAND\`
  on the DOS PATH): `CACHE OFF`/`CACHE ON` toggles the CPU L1/L2 cache
  (CR0.CD/NW) to slow the Pentium for speed-sensitive old games. Real-mode
  only — must run in MS-DOS mode.

## Gotchas (read before working on this box)

- **Genuine Pentium 1 = no CMOV.** Any binary with CMOV/MMX/SSE dies with
  `STATUS_ILLEGAL_INSTRUCTION` (0xC000001D). Build i586 **and** CMOV-free:
  `-D__USE_MINGW_ANSI_STDIO=0` (routes stdio to msvcrt) and no `__thread`
  (use native Win32 TLS) — the MinGW runtime otherwise injects i686 CMOV. The
  agent (v1.15.6+) and `hwscan.exe` are built this way. See
  [`../../agent/src/main.c`](../../agent/src/main.c) header for the full crash
  history on this box.
- **Extremely slow / memory-starved (31 MB).** Use huge client timeouts
  (connect 90–180 s), query it sparingly, and **always close gracefully**
  (Win98 RST-crash rule).
- **Win98 = COMMAND.COM, not cmd.exe.** Any batch aimed at this box must use
  the Win9x dialect (no `cmd`, `2>&1`, `setlocal`, `%~`, `set /a`, `goto :eof`,
  `call :label`; labels unique within 8 chars).
- **Onboarding is on demand** (agent v1.16.0) — send `ONBOARD`; it stages
  wallpaper only (all games gate out on this hardware). See the
  `onboard-machine` skill.
- **Share mapping is intermittent** on this box (its `E:` drops), so its
  agent.log doesn't reliably auto-upload to the share.

# P3-DUAL — 192.168.1.133

Windows XP SP3 (5.1.2600), **dual Pentium III** (family 586, `processor_level 6`),
1023 MB RAM, ~953 GB C:. Agent v1.5.0 on port 9898. `Z:` maps to the SMB file
share. This is one of the machines the Retro Chat bridge is commonly driven from.

## CPU: no SSE2 (important)

The Pentium III has SSE but **not SSE2** (SSE2 arrived with the Pentium 4). Any
Windows binary compiled with SSE2 instructions dies with
`STATUS_ILLEGAL_INSTRUCTION` (0xC000001D) the instant that code executes — with
**no** Application-log entry and **no** crash dump, so it looks like a silent
hang or black screen.

Practical rules for this box:

- Prefer **i486 / i686 / "win2000"** build variants of any wrapper or tool.
- Avoid CnCNet's modern `gamemd`/`clientdx` and other SSE2-only game frontends.
- Verify a candidate DLL/EXE is SSE2-free before deploying:
  `i686-w64-mingw32-objdump -d file.dll | grep -i xmm` should be empty.

See [`../case-studies/003-red-alert-2-pentium3-sse2-cnc-ddraw.md`](../case-studies/003-red-alert-2-pentium3-sse2-cnc-ddraw.md).

## GPU

| Field | Value |
|---|---|
| Adapter | NVIDIA GeForce4 Ti 4600 (PCI `10DE:0250`) |
| Driver | ForceWare **93.71** (6.14.10.9371), 2006-10-22, `oem14.inf` |
| DirectX | 9.0 (4.09.00.0904) |
| Desktop mode | 1024x768, 32-bit, 100 Hz |

93.71 is the **last** NVIDIA driver that supports the GeForce4 Ti series on XP —
there is nothing newer to install. The card is OpenGL 1.4 / DX8-class hardware,
so DirectDraw wrappers must use a **GDI** renderer (not OpenGL 2.0 / Direct3D9).

## Games

Installed under `C:\Program Files\EA GAMES`, `C:\Games`, `Sierra On-Line`, and
`MSN Gaming Zone`; desktop shortcuts for Unreal Tournament, Medal of Honor:
Allied Assault, and Counter-Strike 1.6. RivaTuner 2.24, PowerStrip, and SpeedFan
are installed (overclock/monitoring utilities).

### Red Alert 2 (working config)

"Win10 Fixed" CnCNet repack at `C:\Games\COMMAN~1\RA2`. Runs via the **SSE2-free
cnc-ddraw i486 build** with a GDI, windowed, `noactivateapp=true`,
`singlecpu=true` `ddraw.ini` (no `tshack`). Launch with
`[1] Launch C&C Red Alert 2.bat`. Full write-up and the exact `ddraw.ini` are in
[case study 003](../case-studies/003-red-alert-2-pentium3-sse2-cnc-ddraw.md).

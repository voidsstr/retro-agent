# haloce-coop-server - Halo Custom Edition campaign co-op (Coop Evolved)

Added 2026-11-13 for a three-player co-op night. UDP **2302** on 192.168.1.132.

| piece | version | from |
|---|---|---|
| haloceded.exe + sapp.dll + sappinj.dll | SAPP 10.3.2 (its own modified 1.0.10 dedicated server) | `mercury install sapp` |
| lua/compat53 | luacompat53 1.0.0 | `mercury install luacompat53` - the zip uses backslash paths, so Mercury on Linux fails to place it; copied by hand |
| sapp/lua/mimic_server.lua | Mimic 4.1.1 (AI + event sync) | `mercury install coopevolved` |
| sapp/lua/coop_evolved_server.lua, maps/*_coop_evolved.map | Coop Evolved 1.10.1 | same |
| maps/bitmaps,sounds,loc,ui.map | Halo CE 1.0 installer payload | Games-Library/HaloCE |

Layout on the host: `~/haloce-server/{game,data,_run}`. `game/` is the server's
install dir, `data/` its `-path` profile dir (SAPP reads `data/sapp/init.txt`).

* `load.txt` (-> `data/load.txt`) and `sapp-init.txt` (-> `data/sapp/init.txt`)
  were generated by `mercury serve --mapcycle coop_evolved --scripts mimic_server
  coop_evolved_server -p 2302` (run once with a stub `wine` on PATH to capture
  them), then `sv_name`/`sv_rcon` set. rcon password: the fleet's `retroadmin`.
* `run-haloce-server.sh` runs `wine haloceded.exe -path Z:\hce\data -exec
  Z:\hce\data\load.txt -port 2302` in `retro-wine:bookworm`, `--net=host`;
  stdin is a `sleep infinity` pipe so the console never sees EOF.
* Unit: `units/haloce-coop-server.service` (+ the shared 10-wait-docker drop-in).
* Probe: `gameservers.py probe_halo` - GameSpy 2 on the game port.

The client side is the staged title `Games-Library/HaloCE` (Chimera r1042 +
Balltze 1.3.5 + Mimic + the same maps); see its NOTES-haloce.txt. Clients and
server must carry the SAME map builds - update both together.
